# Media provenance

Images committed for the README. All are original captures/exports from this project — they are
not stock photography.

| File in this folder | Original filename | What it shows |
|---|---|---|
| `vision-demo.png` | `VISION IMPLEMENTATION.png` | The demo unit I built to test the full process: an improved version of the tracker from the [inspiration video](https://www.youtube.com/watch?v=zXX4d5eyvb8&t=152s), configured as close as possible to the final vision design for on-ground use in dense-forest, low-income communities in Cameroon. Used as the README hero image. |
| `pcb-design.png` | `com.png` | The two-layer PCB design of the tracker electronics (the circuit consolidated from the breadboard). |
| `breadboard-prototype.png` | `io.png` | The breadboard prototype: four-quadrant LDR sensing, the pan and incline servos and the controller wired together to validate the process. |

The Fritzing source that produced the breadboard/PCB views lives in
[`hardware/`](../../hardware/) and is re-parsed by the repository integrity tests on every push.
